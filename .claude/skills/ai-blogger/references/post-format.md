# Формат файла статьи

Файл: `content/blog/<slug>.md`. Имя файла и есть slug (латиница, kebab-case). Сборка (`npm run build`)
проверяет frontmatter и падает с понятной ошибкой, если что-то не так.

## Frontmatter

```yaml
---
title: "Окупится ли ИИ в вашем бизнесе: как посчитать до внедрения"   # H1, до 65 символов
seoTitle: "Окупаемость ИИ в бизнесе: как посчитать"                    # необязательно, для <title>
description: "140–160 символов: ключ + польза или цифра."
date: 2026-10-26                 # дата публикации
updated: 2026-11-15              # необязательно, при обновлении фактов
tags: ["Окупаемость", "ИИ-агенты"]            # 1–3 тега из уже существующих, если подходят
keywords: ["главный ключ", "доп. ключ 1", "доп. ключ 2"]   # главный — первым
summary:                         # блок «Коротко», 3–5 пунктов
  - "Пункт с цифрой или выводом."
faq:                             # 3–5 вопросов; ответы 40–70 слов
  - q: "Вопрос так, как его задают?"
    a: "Самодостаточный ответ."
sources:                         # все внешние источники статьи
  - title: "Заголовок материала"
    url: "https://..."
    publisher: "Издание или компания"
    date: 2026-10-20
draft: false                     # true — статья не попадёт на сайт
---
```

## Тело статьи

- Без H1 (`#`): заголовок статьи — это `title`. Разделы — `##`, подразделы — `###`.
- Сырой HTML не используется: сайт покажет его как текст.
- Таблицы — Markdown (GFM). Ссылки — `[текст](url)`. Внутренние ссылки — `/blog/<slug>/`.

## Скелет

```markdown
Первый абзац: прямой ответ на запрос в 2–3 предложениях, с главным ключом.

Второй абзац: для кого статья и что читатель получит (расчёт, чек-лист, план).

## Подвопрос 1 из выдачи

Ответ в первом предложении, затем детали, цифры с источниками, пример.

## Подвопрос 2

…

## Пример расчёта / разбор кейса

Таблица или пошаговый расчёт с явными допущениями.

## Что сделать на этой неделе

1. Глагол + конкретное действие.
2. …

Короткий финальный абзац без «В заключение»: последний конкретный совет или вывод.
```

FAQ, источники, блок автора и призыв к действию сайт добавляет сам из frontmatter — в тело их не пиши.
